# AI Lead Analyzer

## Назначение
Программа читает CSV-файл с лидами, группирует их по каналам
(email / call / web), считает количество лидов, число оплат,
конверсию в оплату и суммарную выручку. Результат сохраняется
в отдельный CSV-отчёт.

Программа НЕ делает:
- не подключается к интернету и внешним API
- не отправляет письма и не звонит
- не пишет в базы данных
- не изменяет входной файл
- не хранит данные между запусками

## Требования
- Windows 10/11 x64
- Python 3.14.7 (проверено), минимум 3.10
- PyCharm Community / Professional (любая свежая версия)
- Только стандартная библиотека Python: csv, collections, pathlib
- Внешних зависимостей нет, pip install не требуется

## Получение и запуск с нуля
1. Скачать ZIP с GitHub или выполнить:
   git clone https://github.com/kraveev413-hash/PythonProject1.git
2. Открыть папку проекта в PyCharm: File → Open.
3. Создать виртуальное окружение:
   python -m venv .venv
   .venv\Scripts\activate
4. В PyCharm: File → Settings → Project → Python Interpreter → Add →
   Existing → .venv\Scripts\python.exe
5. Запустить:
   python main.py

## Входной файл
Путь: data/leads.csv
Формат: CSV, UTF-8, разделитель — запятая.
Колонки:
- id       — идентификатор лида, дубли отбрасываются (остаётся первый)
- channel  — канал: email, call, web (обязательное)
- status   — статус: new, contacted, paid (обязательное)
- amount   — сумма, число; пустое значение = 0

Пустые channel или status → строка пропускается.
Пустой amount → считается как 0.
Дубли по id → остаётся первая запись.

## Выходной отчёт
Путь: report.csv в корне проекта.
Колонки: channel, leads, paid, conversion, revenue.
Конверсия считается по формуле:
    conversion = paid / leads * 100
Округление до 2 знаков. Если leads = 0 → conversion = 0.
revenue — сумма amount по лидам со статусом paid.

## Проверки
| ID  | Проверка                          | Ожидаемо                     |
|-----|-----------------------------------|------------------------------|
| T01 | Запуск python main.py             | Отчёт с 3 каналами           |
| T02 | Файл leads.csv отсутствует        | Сообщение "Не найден файл"   |
| T03 | Один лид, paid                    | leads=1, paid=1, conv=100    |
| T04 | Дубль по id                       | Считается один раз           |
| T05 | Пустой channel                    | Строка пропущена             |
| T06 | Все лиды paid                     | conversion = 100 для канала  |
| T07 | Нет paid                          | conversion = 0               |
| T08 | Пустой amount у paid              | revenue += 0                 |
| T09 | Нечисловой amount ("abc")         | amount = 0, без падения      |
| T10 | Несколько каналов одновременно    | Отдельная строка по каждому  |

Фактические результаты проверок фиксируются вручную после запуска.

## Ограничения
- Поддерживается только CSV, XLSX не читается.
- Нет аргументов командной строки (пути зашиты в main.py).
- Файлы > 100 000 строк обрабатываются медленно (однопоточно).
- Нет логирования, только print в консоль.
- Нет валидации id: пустой id тоже дедуплицируется.
- Кириллица в путях Windows может ломать чтение — используй латиницу.
